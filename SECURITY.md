# Security Policy

## Supported Versions

Security updates and critical patches are released for the following versions of **Node Player**:

| Version | Supported          |
| :------ | :----------------- |
| 1.0.x   | :white_check_mark: |
| 0.1.x   | :x:                |

---

## Reporting a Vulnerability

We take the security and privacy of our users seriously. If you discover a security vulnerability within Node Player:

1. **Do not disclose the issue publicly** via public GitHub issues, discussions, or social media.
2. Report the vulnerability privately via **GitHub Security Advisories** on the [Krighz/node-player repository](https://github.com/Krighz/node-player/security/advisories/new).
3. Provide detailed steps to reproduce the vulnerability, including affected device models, Android OS versions, and sample files if applicable.

### Response Timeline
- **Initial Response**: Within 48 hours of report submission.
- **Triage & Status Update**: Within 5 business days.
- **Remediation & Patch Release**: Security fixes will be prioritized for inclusion in the next point release.
