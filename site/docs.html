DSP Core

32-Bit Signal Path & Direct Sinks

Node Player operates on an end-to-end 32-bit floating-point audio pipeline. Unlike standard audio players that convert decoded audio frames into 16-bit integers before applying digital signal processing, Node Player keeps samples in IEEE 754 float32 format from initial decoding through all biquad filter nodes, volume scaling, and limiter stages.

Audiophile Principle: Processing at 32-bit float provides over 1500 dB of internal dynamic range, eliminating intermediate truncation artifacts and cumulative rounding noise.

Platform Output Architectures

Windows Desktop (WASAPI Exclusive): Communicates with native WASAPI endpoints via JNA bindings. When exclusive mode is engaged, Windows audio session mixer is bypassed, locking the hardware sample rate directly to the source media rate (44.1 kHz, 48 kHz, 96 kHz, or 192 kHz).

Android ART (Direct AudioTrack Sinks): Leverages AndroidX Media3 ExoPlayer with customized audio attribute flags (USAGE_MEDIA, CONTENT_TYPE_MUSIC). On supported Android HAL implementations, the stream routes through offloaded direct sink paths.

Headphone Correction

AutoEQ Headphone & IEM Profiles

Node Player includes a high-speed parametric AutoEQ engine featuring verified compensation curves for prominent audiophile IEMs and consumer headphones (Sony WH-1000XM4/XM5, Sennheiser HD 600/650, Moondrop Aria/Chu, Tangzu Wan'er, 7Hz Zero, AirPods Pro 2).

// Sample 10-Band Biquad Filter Coefficients Calculation val q = 1.414f // Standard 1-octave bandwidth val alpha = sin(w0) / (2.0f * q) val a0 = 1.0f + alpha / A val a1 = -2.0f * cos(w0) val a2 = 1.0f - alpha / A

Each preset automatically configures center frequencies, Q-factors, and gains across 10 parametric peaking biquads, aligning headphone acoustic output to the standardized Harman target.

Cross-Device Mesh

Node Connect P2P Setup & QR Pairing

Node Connect enables cross-device control, mutual library access, and lossless Wi-Fi PCM audio casting between Windows PC and Android devices over your local area network without requiring third-party cloud servers or router port forwarding.

Pairing Sequence

1. Open Node Connect on both devices (or tap the Device Connect pill in the top header).

2. On Desktop, display the pairing QR code. On mobile, scan the QR code using the integrated zero-dependency barcode reader.

3. The devices perform a mutual TLS (mTLS) handshake with ephemeral 2048-bit RSA keys, establishing a TLS encrypted framing stream on port 54820.

Visual Shaders

AGSL Liquid Glass Shaders & Diagnostics

The liquid glass UI utilizes custom Android Graphics Shading Language (AGSL) shaders running on the GPU (Android 13+ / API 33+). On older Android releases (API 26–32) or desktop platforms with software OpenGL, Node Player gracefully engages its Safe Graphics diagnostic fallback.

Safe Graphics Guard: If a GPU crash or shader link error occurs during initialization, the engine flags the failure and safely falls back to standard Material 3 elevated glass surfaces without interrupting audio playback.

Data Freedom

.nodebackup Data Portability

Node Player stores zero user data on remote clouds. All playlists, favorites, equalizer configurations, custom folder rules, and playback histories can be exported as an encrypted or plain .nodebackup archive via Settings → Storage & Backup.

// Archive Manifest Schema { "version": 4, "exportedAt": 1732000000000, "playlists": [ ... ], "favorites": [ ... ], "eqPresets": [ ... ], "appSettings": { ... } }

The .nodebackup archive is fully cross-platform and can be imported into Node Player on Windows or Android interchangeably.

Background Service

Battery Optimization & ColorOS / Realme UI

Modern Android operating systems (including OxygenOS, ColorOS, Realme UI, MIUI, and One UI) enforce aggressive background task management that can terminate long-running media foreground services if battery restrictions are applied.

Recommended Configuration:

1. Long-press the Node Player app icon → App Info → Battery usage.

2. Select "Unrestricted" (or enable "Allow background activity" and "Allow auto-launch").

3. Under Settings → Battery → More settings → Optimize battery use, mark Node Player as "Don't optimize".
