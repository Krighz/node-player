Release History

Evolution of Node Player

Detailed engineering updates and changelogs from v2.1.0 to v0.1.0.

v2.1.0 Added Perf Fixed 2026-11-23

Google Drive Cloud Sync, Landscape FullScreen Lyrics & Audiophile Refinements

  • Opt-In Privacy-First Google Drive Cloud Sync: Serverless backup to personal Google Drive using hidden appDataFolder (spaces=appDataFolder) with zero developer-hosted servers. Safe merge conflict resolution, dirty-flag background optimization via WorkManager (Hourly, Daily, Manual), and hardware Keystore AES-256-GCM token encryption.
  • Two-Column Landscape FullScreenLyricsView: Split-screen architecture featuring shapeable album art hero, song name, time-seek timeline slider, and playback controls on the left, with synchronized lyrics on the right.
  • Auto-Collapsing Left Hero Controls: 4.5-second inactivity auto-collapse for landscape transport controls that smoothly tucks into the screen edge when playing.
  • Shapeable Album Art Customizer: Choose between Squircle, Circle, and Heart shapes with smooth cubic Bezier vector clipping via the top-right three-dot menu (⋮).
  • Selectable Lyrics & Highlighting: Direct on-screen word and line selection across full-screen lyrics with SelectionContainer.
  • Multi-Provider Expansion & State Indicators: Integrated Musixmatch (with duration tolerance matching) and Unison, with visual status icons (Searching, Found & Connected, Fallback).
  • Offline Romanization & Dual-Line Translation: Embedded multi-script engine for Japanese, Korean, Chinese, Cyrillic, Greek, Hindi, and Arabic phonetics via an interactive 50% bottom sheet.
  • Genuine Listening Metrics: Replaced placeholder library listening time and play count fallbacks with real-time statistics from daily stats and track play counters.
  • 1200p Ultra-HD Cover Art Pipeline: InnerTube transformer automatically upscales album covers to crystal-clear 1200×1200p resolution.
  • Audio Engine & Decoder Reliability: 32-bit float audio sink clamp for older Android devices, Vorbis/Opus tag parser resilience, and cold-start replay HTTP 403 prevention.
v2.0.0 Added Perf Fixed 2026-11-19

The Complete Liquid Glass & YouTube Music Revamp

  • Universal Brand Mark Rollout: Finalized curved 'N' musical note logo embedded across Android, Windows Desktop, Compose vectors, and GitHub Pages.
  • 5-Provider Word-by-Word Karaoke: Sub-pixel 120 FPS sweep powered by BiniLyrics, BetterLyrics, LyricsPlus, LrcLib, and KuGou with TTML syllable timing.
  • 1080×1920 & 4:3 Lyric Cards: Interactive multi-line selection dock with dynamic album art vertical ambient gradients and native Android Share Sheet integration.
  • Full Interactive Artist Pages: Edge-to-edge 380dp hero portraits, Shuffle/Play/Follow controls, Latest Release spotlight, and 7 categorized discography shelves.
  • Smart Offline Mixtape: Autonomous Wi-Fi caching (60% discovery + 40% heavy rotation) with intelligent two-tier LRU eviction.
  • Unthrottled Stream Startup: Dropped YouTube audio stream latency from 14s to ~1.1s via direct NewPipe fallback deciphering and 128 KB chunking.
  • Zero-Recomposition Now Playing Tickers: Migrated position/scrubber tracking to leaf-level produceState coroutine tickers, eliminating whole-screen redraws.
  • Hardware-Synced Volume Control: Real-time bidirectional synchronization with Android AudioManager.STREAM_MUSIC.
v1.8.0 Added Perf November 2026

Dual-Platform Foundation & 120 Hz Display Lock

  • Added automatic display refresh rate query and 120 Hz lock on supported hardware.
  • Integrated Kyant AndroidLiquidGlass components with hardware AGSL shaders.
  • Introduced studio-grade 32-bit float DSP pipeline with 10-band biquad parametric EQ.
  • Added AutoEQ headphone database integration with Harman target compensation.
  • Launched Windows Desktop 16:9 Compose Multiplatform experience with WASAPI audio.
v1.7.0 Added Fixed October 2026

Node Connect P2P Mesh & Crossfade Engine

  • Introduced Node Connect: Local Wi-Fi 16-bit 48kHz PCM casting between Windows and Android.
  • Implemented mutual-TLS (mTLS) handshake with zero-dependency QR code pairing.
  • Added Dual-Player continuous crossfading with Equal-Power, Linear, and Logarithmic curves.
  • Fixed audio pipeline pops during track boundary transitions via dual ExoPlayer isolation.
v1.5.0 Added October 2026

Local Library Architecture & Room Persistence

  • High-speed audio metadata extraction for FLAC, WAV, AAC, and MP3.
  • SQLite Room persistence layer with compound indices achieving <15ms queries.
  • Added smart playlists, duplicate track detection, and folder exclusion filters.
  • Offline Last.fm scrobbler caching with exponential backoff retry queue.
