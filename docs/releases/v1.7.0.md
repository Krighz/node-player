# Node Player 1.7.0 - Liquid Glass

> **Heads-up: performance.** This release uses real-time glass effects (blur, refraction, vibrancy) everywhere. Expect lower frame rates, more GPU use, more battery drain and a warmer phone, especially on mid-range and older devices and on pages with many controls (Equalizer, Settings, long lists). Go to **Settings → Customize UI** and toggle **Enable Liquid Glass** off or enable **Performance Mode** to switch to lightweight plain squircles and reduce GPU load. Performance work is planned for the next version. If something is badly slow or crashes, please open an issue with your device model.

## Highlights
- Complete liquid glass visual redesign powered by the Kyant0 AndroidLiquidGlass backdrop shader library.
- Native Compose 1.7 & Kotlin 2.0.21 upgrade with hardware RenderEffect execution on Android and Skia ImageFilter on Windows.
- Convx-style floating capsule dock with sliding tab puck, dynamic lens refraction, and intelligent scroll auto-hiding.
- Custom liquid control design system: tactile spring-based `LiquidSlider`, `LiquidToggle`, `LiquidChip`, and buttons.
- Dedicated Optical Diagnostics test screen and deep real-time customization settings with live GPU cost metering.

## New
- Floating 64dp capsule dock (`ConvxLiquidDock`) with continuous squircle border, sliding tab puck, and companion floating Search button.
- Floating squircle mini-player capsule (`ConvxMiniPlayer`) sampling the live page backdrop with integrated squircle cover art and real-time visualizer.
- Intelligent nested scroll dock auto-hiding with return-on-up-scroll and velocity awareness across Android and Windows.
- Comprehensive liquid control suite: `LiquidSlider` (48dp touch hitbox, velocity stretch, continuous dragging), `LiquidToggle`, `LiquidChip`, `LiquidRadioButton`, and `LiquidCheckbox`.
- Dedicated Optical Diagnostics test screen (`Settings → Diagnostics & Graphics → Liquid Glass Optical Test`) with triple-zone contrast test pattern.
- Customize UI suite with live preview canvas, real-time GPU cost estimation, 9 component override accordions, and two-tier reset engine.

## Fixes
- **Both**: Fixed RenderNode cyclic self-sampling infinite recursion (`prepareTreeImpl` 512-frame stack overflow SIGSEGV) on Equalizer and Settings screens via `LayerBackdrop` `isRecording` guard and `LocalControlBackdrop` scoping.
- **Android**: Eliminated dead Compose 1.6 `GraphicsLayer` shim where stored `renderEffect` was never rendered; upgraded to native Compose 1.7 hardware RenderEffect compositor.
- **Android**: Fixed black dock rendering by switching from unhandled reflection on `Paint` to hardware-backed `Modifier.graphicsLayer(colorFilter)`.
- **Android**: Fixed crash on launch by adding non-finite float and unspecified size guards during backdrop effect scope initialization.
- **Android**: Replaced legacy ChrisBanes Haze references with native Kyant0 backdrop shader pipeline.
- **Windows**: Ensured multiplatform compatibility with Skia ImageFilter desktop fallback and 60fps hardware rendering.

## Changed
- Upgraded Kotlin to `2.0.21`, AGP to `8.5.2`, Compose Multiplatform to `1.7.3`, KSP to `2.0.21-1.0.28`, and Compose BOM to `2024.10.01`.
- Completely purged legacy `dev.chrisbanes.haze` dependencies and wrappers.
- Replaced Material3 Slider, Switch, FilterChip, AssistChip, and RadioButton across all screens with native Liquid controls.
- Centralized `GlassControlsConfig` model with versioned JSON serialization and two-tier reset engine.
- Re-architected root window Compose layout to sample page content into `pageBackdrop` with floating chrome overlays positioned as siblings above in z-order.

## Known issues
- Performance: see the note at the top.
- Windows Authenticode Signing: Unsigned MSI and portable EXE trigger Windows Defender SmartScreen "Unknown Publisher" prompt on initial run (click "More info" → "Run anyway").
- Windows Firewall: Node Connect discovery on port 47200 may prompt for local private network permission.
- Android Emulator Shader Variances: Software/host GPU virtualization in Android Emulator may exhibit subpixel coordinate quantization; hardware AGSL shaders require physical ART hardware (API 26+).
- Release build has only been verified on Android 16 (realme RMX3853) and Windows 11 x64 physical hardware; other Android vendors/SoCs are unverified in this release.

- Android: allow installing from unknown sources; it installs over 1.6.x (same signature).
