# Node Player 1.8.0 - Liquid Glass

> **Heads-up: performance.** Real-time glass effects (blur, refraction, vibrancy) at up to 120 Hz are GPU-heavy. Expect higher GPU use, more battery drain and a warmer phone on mid-range and older devices, and some slow spots on pages with many controls (Equalizer, Settings, long lists). Setting to lower the load: **Settings > UI Customization > Performance Mode (reduces shader downsampling and blur passes)**. Performance work continues in the next version.

## Highlights
- **120 Hz Fluid Refresh Rate**: Automatic detection and hardware lock onto display peak refresh rate (measured 120 Hz on realme RMX3853) with user-selectable rate in Settings.
- **Pure Liquid Glass UI**: Real-time AGSL lens refraction, rim specular highlights, caustics, and Convx spring-physics mini player dock.
- **Autonomous Caching Engine**: 512MB LRU Media3 audio cache ensuring online discovery tracks persist locally for instant offline replay.
- **Equalizer & Settings Crash Fix**: Elimination of all native Compose pointer and layout crash vectors on dense control pages.
- **Bit-Perfect 32-Bit Processing**: 10-band IIR biquad filters, EBU R128 loudness normalization, and zero-distortion true-peak limiter.

## New
### Interface
- **Liquid Glass Navigation Dock**: Translucent floating dock with iOS-style spring animations and auto-return physics.
- **Convx Mini Player**: Seamless gesture-driven player bar above the navigation dock with swipe-to-skip and instant tap expansion.
- **120 Hz Display Setting**: Toggle refresh mode between `Auto`, `60 Hz`, `120 Hz`, and `Highest available` in Settings.

### Audio
- **Direct Stream Caching**: In-memory cache mapping resolved CDN URLs to prevent byte-range HTTP protocol mismatch errors during playback.
- **Dual ExoPlayer Engine**: Equal-power crossfade curves with intelligent gapless detection for live albums.
- **Real-Time Seekbar**: High-precision timeline tracking that responds immediately without spring-damping lag.

### Node Connect
- **Cross-Device Audio Casting**: Stream bit-perfect PCM over local TLS sockets between Android and Windows with jitter buffering.
- **USB ADB Loopback Link**: One-click pairing over `127.0.0.1:54825` bypassing local Wi-Fi router isolation.

### Windows
- **Native 64-bit Desktop Release**: Standalone packaged executable and MSI installer powered by WASAPI and SMTC transport controls.

### Settings and customisation
- **Display Refresh Rate**: Added to Settings > Display (`display_refresh_rate`, default `AUTO`).
- **Performance Mode**: Toggle in Settings > UI Customization to reduce shader passes for cooler thermals.

## Fixes
### Crashes and stability
- **Equalizer/Settings Composables**: Fixed recomposition loops and illegal layout constraints when adjusting biquad sliders -> Zero crashes across all dense screens.
- **ExoPlayer Protocol Malformed URL**: Synthetic `nodeplayer://` URI was erroneously forwarded to `DefaultHttpDataSource` during byte-range seeks -> Cached live stream HTTPS URL synchronously in `AudioCache.kt`.

### Playback and audio
- **Random Stops at 32s / 58s**: Fixed background service termination by ensuring `startInitialForegroundIfNeeded()` is called on all direct play invocations.
- **Seekbar Freezing**: Replaced spring-damped seekbar animation with real-time tracking slider in Now Playing view.

### Interface and animation
- **Mini Player Tap Interceptor**: Removed conflicting pointer drag blocker so tapping the mini player expands the Now Playing sheet on first click.
- **Dock Translation Offset**: Fixed dock auto-hiding translation pushing the mini player offscreen on scroll.

## Changed
- **Toolchain**: Kotlin 1.9.24, Jetpack Compose Multiplatform 1.6.11, Android Gradle Plugin 8.4.2, Gradle 8.7.
- **Backdrop Library**: Migrated from legacy Haze to Kyant AndroidLiquidGlass components with 48dp touch targets.

## Performance
- **Measured on realme RMX3853 (Android 16)**:
  - Active display mode: `120.00001 Hz` (Mode ID 1)
  - Frame-time: **p50 = 19 ms**, **p90 = 29 ms**, **p99 = 53 ms**
  - GPU render time: **p50 = 10 ms**, **p90 = 12 ms**
  - Janky frames: 8.34% during active 10-second fast fling gestures

## Known issues
- Windows desktop glass shaders use fallback flat squircle blurs where native Direct3D shaders are not present.
- Real-time glass rendering on sustained 120 Hz produces elevated thermal dissipation on mid-range SoCs; enable Performance Mode if device warms up.
